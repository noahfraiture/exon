*helix.txt*     Native selection-first editing

NATIVE HELIX MODE                                    *helix-mode*

Enable the native mode in Lua: >lua
    vim.o.helix = true
<
Or use :set helix / :set nohelix. The default is off.

Optional command configuration: >lua
    vim.helix.setup({
        surrounds = { c = {'/*', '*/'} },
        keymaps = { ['<Space>s'] = 'ms' },
    })
<
setup() enables the mode unless enabled=false is supplied. Built-in pairs
already work: ms( wraps selections in parentheses; ms" adds quotes. No
per-character mappings are needed. A custom pair key is shared by ms, mi, ma,
mr, md and nearest-surround selection: msc, mic and mac use the example above.
Custom keys must be one character other than m, w, W or p. Delimiters can
contain multiple characters, but must be nonempty single-line strings without
NUL. Custom pairs supplement the defaults. Matching is lexical.

keymaps entries are strings, callbacks or false (<Nop>), in the "h" namespace.
Omitted surrounds are retained on repeated setup; surrounds={} clears custom
pairs. Supplied keymaps update their keys, leaving other mappings alone.
vim.helix.surround('(') wraps every selection directly.
vim.helix.replace_surround('"', "'") replaces surrounding double quotes with
single quotes; vim.helix.delete_surround('m') deletes the closest surround.
Command argument keys are literal, so a mapping of "w" does not affect miw.

Helix normal mode selects text while moving. It reports "h" through mode()
and nvim_get_mode(). Selection extension (v) reports "hv" through mode(1).
Insert mode is real
Neovim Insert mode and reports "i". Use the "h" mapping namespace: >lua
    vim.keymap.set('h', '<Space>w', '<Cmd>write<CR>')
    vim.keymap.set('h', 'Q', function() vim.helix.textobject('m') end)
<
mim selects inside the closest enclosing surround. mi( selects inside
parentheses. ma/ includes the surrounding slash delimiters. miw selects a word.
mr reads the old and new pair keys: mr"' changes "hello" into 'hello'; mr([
changes parentheses to square brackets. md" removes surrounding double quotes.
Use m for the old pair to select the closest surround: mrm' or mdm. A prefix
count selects the nth enclosing pair, e.g. 2mr([. Custom pair keys work too.
Replacement/deletion retain the selected content, direction and primary index,
and return to Helix normal mode. All cursors change in one undo step, including
cursors sharing a pair. Missing pairs or conflicting shared delimiters leave
all text and selections unchanged. Escape cancels either replacement argument.
x selects lines; C adds a selection on the next line; comma keeps the primary.
i/a/c insert/append/change at selections. u/U use native undo/redo.

Special, readonly and unmodifiable buffers use Vim editing. Set b:helix to
v:false to exclude another buffer. vim.pack can install companion plugins;
the native mode itself requires this fork's executable and matching runtime.

Insertion uses upstream 0.13 multicursor contexts, with native mappings,
indentation and control keys. Compatible completion retains the cursors and
applies the primary candidate at each location. Independent per-cursor LSP
requests and snippet groups are not implied. Built-in snippet placeholders use
Vim Select mode; external completion/snippet plugins need workflow validation.
o/O and I/A use native entry and indentation. >/< indent selected lines once;
J joins selected lines, or the next line for a single-line selection. They use
native indentation/whitespace options; disjoint ranges undo together.
vim.helix.indent(true, 2) indents two levels; vim.helix.join() joins lines.
Insert cursor movements retain native undo boundaries. Macro/dot-repeat parity
is outside the required editing baseline.
Extra selection undo metadata is session-local; text undo-file compatibility is
preserved. Full Helix command and plugin compatibility is not implied.

The additive fork APIs are nvim_helix_get_state(), nvim_helix_set_selections()
and nvim_helix_apply_edits(). Ranges are half-open, use zero-based rows/byte
columns, and must be ordered and non-overlapping. Primary indices are one-based.
Replacing selections during native Insert mode is rejected; the native cursor
engine owns them until insertion ends. Selection reads remain available.

See HELIX.md in the source repository for installation, supported commands,
examples, configuration, limitations and testing instructions.
